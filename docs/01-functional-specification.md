# 機能仕様

## アカウントと予約者情報

本システムでは、ログインアカウントと予約時の顧客情報を分離します。

### Account

- ログインする利用者だけを登録する
- Firebase Authentication UIDと紐付ける
- 氏名、メール、電話、住所、旅行代理店情報等のプロフィールを保持する
- Account変更は過去予約へ反映しない

### Reservationの予約者情報

- 予約時点の氏名、メール、電話、住所、会社・支店、担当者等を保存する
- 管理者代理予約・非会員予約でも予約者情報を保存できる
- 管理者代理予約・非会員予約ではAccountを作成しない
- メールアドレス等が既存Accountと一致してもAccountへ紐付けない

### ログイン済み予約

ログイン済み本人が予約した場合だけReservation.accountを設定する。マイページにはこの関連を持つ予約だけを表示する。

### 過去予約の扱い

新たにAccountを作成しても、過去の管理者代理予約・非会員予約は紐付けない。メール一致による自動統合もしない。

## 予約管理

予約は仮予約・本予約・変更・キャンセル・来店までの状態を管理する。予約者情報は予約ごとのスナップショットとして保持する。
