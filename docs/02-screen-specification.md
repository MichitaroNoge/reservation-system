# 画面仕様

## 管理画面

従来の「顧客管理」は、ログイン可能な利用者を対象とする「アカウント管理」として扱います。

管理者が予約を代理登録する際に入力した予約者情報はAccount一覧へ自動追加しません。

## 予約画面

- ログイン済み本人: Account情報を初期値に利用可能。ただし保存先はReservationの予約者スナップショット
- 非会員: 入力内容をReservationへ保存し、Accountは作成しない
- 管理者代理登録: 入力内容をReservationへ保存し、Accountは作成・検索しない

## マイページ

ログインAccountに明示的に紐づく予約だけ表示します。メールアドレス等が一致する過去予約は表示しません。
