# ダッシュボードのタスクカード幅統一

承認系だけ4列、内部業務系・催促系は2列だったため、広い画面でカード幅が異なっていた。

共通の `TaskGrid` に置き換え、全グループを同じ列幅・間隔で表示する。640px未満は1列、640px以上は2列、1536px以上は4列。件数バッジは必要に応じて折り返し、カードに `min-w-0` を設定した。抽出条件、件数の計算、遷移先は変更していない。

実際のタスク表示部分とコンポーネントを使った検証用画面で、390・768・1280・1536・1920pxに順にリサイズした。各サイズで8枚すべてのカード幅が一致し、ページの横はみ出しがないことを確認した。検証用件数は0件・123件。認証後の管理画面全体の通し操作は未実施。

`npm test`：127件成功。`npm run build`：成功。
