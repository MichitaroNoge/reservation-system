# 問い合わせ管理一覧の表示・操作の統一

実施日: 2026-10-25

## 依頼

予約一覧・予約承認と同様に、一覧を枠で囲み、明細行から詳細を開けるようにする。

## 変更内容

- 問い合わせ一覧に他の管理画面と同じ外側余白と、角丸8px・1pxの枠を設定。
- 検索・状況・種別を一覧上部に配置。状況・種別はラベルと選択値を同じコントロール内に表示し、件数を右側の「該当 N 件」に統一。
- 一覧を白背景、見出しを淡い背景、行を区切り線とホバー表示に統一。ステータス表示に共通Badgeを使用。
- 明細行のクリックでその問い合わせの中央の詳細ダイアログを表示。文字の選択中は行クリックを抑止。
- 問い合わせ番号をキーボード操作可能なボタンにし、詳細ボタンも継続。各ボタンに問い合わせ番号を含むアクセシブル名を設定。
- スマートフォンでは検索条件を縦に配置し、一覧内だけ横スクロール。詳細ボタンを右端に固定し、タップ領域を44px以上確保。表の文字は12px以上。
- 問い合わせ管理で重複していた一覧外の読み込み表示を除外。読み込み表示の消失で一覧が移動し、意図しない行を選ぶ問題を抑制。
- 読み込み中・エラー・0件時も一覧の枠と検索条件を維持。

## 対象ファイル

- app/reservations/admin-app.tsx（問い合わせ管理の重複した読み込み表示だけを変更）
