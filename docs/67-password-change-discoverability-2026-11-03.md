# パスワード変更の入口と見出しの改善

実施日: 2026-11-03。利用者が提示案を採用したことに基づく確定仕様。

- トップのボタン・子画面のタイトルを「お客様情報・パスワード変更」に変更。
- お客様情報、パスワード変更、Googleアカウント連携、追加の連絡先メールアドレスの順に表示する。
- 「ログイン方法の設定」の折りたたみをなくし、パスワードとGoogle連携をそれぞれ独立した操作欄にする。パスワード入力欄は画面を開いた時点で表示。未設定なら「パスワード設定」と表示する。
- ログイン方法の取得中・失敗・再読み込み、操作中の無効化、入力済みでトップに戻る際の破棄確認は維持する。初回のお客様情報登録は従来どおり扱う。
- 本人確認方法・API・パスワード要件・メール通知・セッション失効は66の仕様を維持。66の折りたたみ開閉に関する記録のみ本変更で置き換える。

共通仕様: [お客様向け画面の共通仕様](customer-screen-standard.md)。

- npm test: 177件成功。
- npm run build: 成功。既存のHook依存警告2件（admin-app.tsx、email-template-management.tsx）は継続。
- 架空アカウントとモック認証・一時PGliteの隔離環境で、実際のNext.js画面を1280px・768px・390px幅で確認。ページ全体の横はみ出しなし。
- トップの新名称のボタンから画面を開くと、追加の展開操作なしで現在のパスワード・新しいパスワード・確認入力が表示される。見出しの順序とGoogle連携の分離を確認。
- Googleのみの場合は「パスワード設定」と表示し、現在のパスワード欄は表示しない。既存の連携解除の無効化と案内を維持。
- 空欄での送信は必須エラーを表示。検証用の入力でトップへ戻ると破棄確認が開き、「入力を続ける」で保持、「破棄して戻る」でトップへ戻る。内部の往復で文書の再読み込み・認証確認表示の増加なし。
- 取得失敗では再読み込みとトップへ戻る操作を表示。実アカウントのパスワード変更・Google連携・実メール送信は実施していない。本番デプロイは対象外。
