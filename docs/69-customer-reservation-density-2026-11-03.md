# 予約確認の表示密度の改善

実施日: 2026-11-03。人数・メニューが大きすぎるためPCで3件程度を一覧できるレイアウトにし、「一般予約」の区分をなくす追加依頼に基づく確定仕様。68の初回の文字サイズ・余白・区分表示を更新する。

## 変更

- 日時・状態・予約ID・「予約内容の詳細」を同じ行に集約。人数は16px、メニューは14pxの太字にし、同じ行で確認できるようにした。
- 大きな背景帯・上下の余白を削減し、カード間8px・カード内余白12pxへ整理。タイトルとログイン情報もPCでは同じ行に配置。各操作ボタンの文字14px・高さ44px以上は維持する。
- 「一般予約」を一覧・詳細から除去。団体名は一覧、旅行会社向けの区分は詳細に表示。予約時の入力内容、申請状況・確認、問い合わせ履歴の有無・本人の閲覧条件は維持する。
- 長文は折り返し、内容や操作を隠してカードの高さを固定しない。画面幅に収まらない操作は折り返す。申請条件・API・DB・管理画面の業務処理は変更しない。
- Tailwindと共通UIを使用し、使わなくなった一覧・上部ログイン情報用の旧CSSを削除した。

- npm test: 177件成功。
- npm run build: 成功。既存のHook依存警告2件（admin-app.tsx、email-template-management.tsx）は継続。
- モック認証・架空予約・一時PGliteを使用するNext.js画面で確認。PC1280×900px、ページ先頭から3件のカード全体と操作ボタンが下部操作欄より上に収まる。先頭は長いメニューを持つ団体予約187px、次の一般予約2件は各163px。3件目の下端778px、下部操作欄の上端823px（検証用の計測欄を含む）。
