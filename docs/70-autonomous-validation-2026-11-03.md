# 自律開発の検証環境整備

実施日: 2026-11-03。既存環境を調査し、不足を最小限整備して検証・修正まで自律的に進める依頼に基づく。

## 調査と変更

- package.jsonにはtypecheck・lint・通常テスト・DBテスト・ビルドが既に存在。TypeScript strict、Next.js 15.5.27、ESLint 9のflat config、Node test runner、tsx、PGlite、Firebase CLIを継続使用した。
- `typecheck`へ`next typegen`を追加し、ビルド済みのルート型に依存しない手順にした。
- Lint対象に設定ファイルも含め、警告0件を要求。既存のHook依存警告2件・未使用型1件と、設定ファイルを新たに検査した際の匿名default export警告を修正。Hookは最新の関数をref経由で参照し、取得の再実行や編集中の入力破棄を増やさない。ルールの無効化は追加していない。
- 通常テストは現在のソースを列挙して実行するため、古い生成済みテストの取り残しを実行しない。
- DBテストはPGlite・直列実行・検証用接続先を固定。実PostgreSQL用の確認値を引き継がない。現在のDBテストを自動列挙し、従来の実PostgreSQLランナーに新しいテストが漏れる問題も修正した。実PostgreSQLランナー自体は今回実行しない。
- `build:check`は既存の`npm run build`を、実認証情報を使わない固定設定と専用`.next-check`で実行。通常／開発用の出力と分離した。
- `test:auth`と専用設定を追加し、既存のFirebase SDK契約テストをローカルAuthエミュレーターで再現可能にした。demoプロジェクト・ループバックホストのみを使用する。
- `verify`で型・Lint・通常テスト・DB・検証ビルドを順番に実行。CIも同じコマンドと認証契約テストを実行し、実FirebaseのSecretsを不要にした。
- 依存関係の追加・更新、DBスキーマ／予約・認証の業務仕様変更はない。Node.js v24.18.0／npm 11.16.0でローカル実行し、CIは既存どおりNode.js 22を使用する。

## エラーと対応

- 通常サンドボックスでAuthエミュレーターの4400番ポートへの確認がタイムアウト。必要なローカル接続権限で同じコマンドを再実行し、契約テスト1件成功と自動停止を確認した。
- 追加した検証コードに対し、Next.jsによるProcessEnvの型拡張がNODE_ENVを必須・読み取り専用にする点を型チェック／ビルドが検出。入力の型を辞書にし、子プロセス用環境を新しいオブジェクトとして構成する方法へ修正。型チェックを迂回していない。
- Firebase CLIの更新確認を検証時は無効化。テストに不要な更新確認・設定ストアへのアクセスを減らした。
