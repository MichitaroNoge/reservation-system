# ダッシュボードの残タスク強調表示

2026-11-05の依頼に基づき、件数を読まなくても対応が必要な項目を区別できる表示に変更した。

- 残タスクが1件以上のカードは共有のwarningトークンによる背景・枠線、「要対応」ラベルとアイコンで強調する。
- 0件のカードは「対応不要」とし、落ち着いた表示にする。0件でも一覧を開ける。
- 次の操作を「対応する」「一覧を見る」で明示する。
- 読み込み中は件数を「—」として操作を無効化する。取得失敗は「取得エラー」と再読み込みの案内を表示し、「対応不要」と誤表示しない。
- 最新の管理画面構成に合わせ、問い合わせ対応を含む全9カードへ適用する。既存のサマリーAPI、集計条件、遷移先、グループ分けは維持する。
- TaskGridの列数と共通のカード幅は維持する。

主な変更箇所は`app/reservations/admin-app.tsx`、`app/reservations/components/common.tsx`。既存のUI回帰検査を新しい件数表示・レイアウトへ合わせた。
