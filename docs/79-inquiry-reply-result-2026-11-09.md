# 問い合わせ回答後の結果表示（2026-11-09）

## 変更内容

- 回答保存後と、回答があり下書きのない問い合わせの再表示では、空の入力フォームの代わりに保存済み回答を表示する。
- 回答の保存と通知メールの配送を分け、送信待ち・送信中は通常の案内、失敗・結果不明は対応が必要な状態として表示する。
- 保存済みの件名・本文・回答日時、メール状態、手動更新、回答履歴への入口を表示。未解決の回答が複数ある既存データでは対象をすべて表示する。
- 失敗したメールは同じメールの再試行、結果不明のメールは送信結果の確認を先に案内する。確認・記録は従来どおり送信履歴の確認とチェックを必要とし、失敗した場合は子画面内で再操作できる。
- 配送解決後は「追加の回答を作成」から入力を開始。切り替えボタンのクリックで新しいフォームが送信されないようにし、未入力エラーが先に出ないことも確認した。
- 下書き保持、送信確認、10秒間隔の画面更新を維持。API・DB・メールキュー・再送制限・会員／匿名の状態判定は変更していない。
- 最新仕様は [回答画面の追加仕様](60-inquiry-reply-layout-2026-10-27.md) と [標準仕様](standard-specification.md) に反映。
